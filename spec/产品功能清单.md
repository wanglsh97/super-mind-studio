# Super Mind Studio 产品功能

Super Mind Studio 是一个 Agent 原生的 AI 创作与任务执行工作空间。用户在持久对话中与 Agent 协作，Agent 可以调用模型、Skill、工具、MCP 插件和隔离 Sandbox 完成任务。

## 用户入口

| 路由 | 功能 |
| --- | --- |
| `/` | Agent 工作台 |
| `/login` | 匿名、GitHub、Google 登录 |
| `/skills` | Skill 市场、已添加 Skill、我的 Skill 与上传 |
| `/plugin` | MCP 插件目录与启停设置 |
| `/creations` | 已保存的图片和视频 |
| `/usage` | 个人 Token 用量 |
| `/admin` | 管理员后台 |

## Agent 工作台

- 创建、查看、重命名和删除对话 Thread。
- 消息、推理、工具调用、用量和运行事件持久化。
- 支持流式输出、断线续传、刷新恢复、后台运行和取消。
- 同一 Thread 同时运行一个任务，不同 Thread 最多并行 5 个任务。
- 可在 Thread 空闲时切换文本模型。
- 支持快速、均衡、深度三档推理强度。
- 支持上下文压缩和跨模型继续对话。
- Agent 可通过结构化问卷向用户追问，并在回答后继续任务。

当前文本模型：

- Qwen3.7-Plus
- GLM-5.2
- DeepSeek-V4-Pro
- DeepSeek-V4-Flash
- Kimi K3

## Agent 工具

- 网页读取与网页搜索。
- Skill 加载。
- Sandbox Shell 命令执行。
- 文件读取、写入和导出。
- 结构化用户追问。
- 网站、图片和视频生成。
- MCP 工具发现与调用。

所有工具由服务端注册和校验，在隔离的 OpenSandbox 中执行文件及命令操作。

## Skill 市场

- 浏览、搜索、分类和排序 Skill。
- 查看 Skill 详情、文件树和文件内容。
- 添加或移除 Skill。
- 在 Agent Composer 中手动选择 Skill。
- Agent 可在任务中自主激活已添加 Skill。
- GitHub 用户可上传 Skill、更新自己的 Skill 和主动下架。
- 管理员可批准、拒绝或强制下架 Skill。

Skill 包存储在私有 OSS，元数据、状态和用户关系存储在 PostgreSQL。

## MCP 插件

- 用户可浏览和启停平台配置的 MCP 插件。
- Agent 根据任务按需发现工具，再通过不透明句柄调用。
- MCP 地址和凭证只保存在服务端。
- 当前支持 Streamable HTTP MCP。

## 网站创作

- GitHub 用户可在 Agent 中进入网站模式。
- 使用 React、TypeScript、Vite、Tailwind CSS、shadcn/ui 和 Lucide 生成静态网站。
- Agent 自动构建并校验网站产物。
- 支持网站预览、源码文件树、代码查看和源码 ZIP 下载。
- 每个 Thread 保留最新一次成功的网站产物。

## 文档操作

- 支持 PDF、DOCX 和 XLSX。
- 单次最多上传 5 个文件，单文件最大 20 MB。
- Agent 可分析、创建、修改、预览和导出文档。
- 文档保存在当前 Thread Sandbox，随 Sandbox 生命周期失效。

## 图片生成

- 在 Agent 中通过自然语言生成或修改图片。
- 支持 Qwen Image、万相、可灵和 Vidu 图片模型。
- 支持参考图、画面比例、质量和水印参数。
- 图片生成任务支持异步恢复和状态跟踪。
- 临时图片保存在 Thread Sandbox。
- 用户可下载图片，或保存到私有 OSS 和“我的创作”。

## 视频生成

- 支持文生视频和单张首帧生视频。
- 支持可灵、HappyHorse、Vidu 和爱诗/PixVerse。
- 默认生成 5 秒、720P、16:9、带音频的视频。
- 同一 Thread 自动复用合适的视频模型。
- 视频任务支持异步恢复、状态跟踪和取消。
- 临时视频保存在 Thread Sandbox并支持在线播放。
- 保存或下载视频时会持久化到私有 OSS 和“我的创作”。

## 我的创作

- 展示已保存的图片和视频。
- 支持图片预览和下载。
- 支持视频悬停播放和下载。
- 资产通过用户隔离的同源接口访问。

## Token 用量

- 展示 input、output、cache 和 reasoning Token 汇总。
- 展示最近一年每日用量热力图。
- 展示每日明细和模型用量占比。

## 用户账号

- 支持一次性匿名、GitHub OAuth 和 Google OAuth。
- 不同登录方式创建独立账号。
- 用户数据和资产按平台 User ID 隔离。
- 用户 Session 与管理员 Session 相互独立。

## 管理员后台

- 固定管理员账号登录和退出。
- 请求量、费用、延迟、错误和 Token Dashboard。
- 请求日志列表、筛选和详情。
- 按 requestId 查看链路追踪。
- 查看白名单数据库表、结构和行数据。
- Skill 审核、拒绝和下架。

## 平台基础能力

- PostgreSQL 持久化用户、Thread、Run、事件、任务、资产、日志、账单和审计数据。
- Redis 提供限流、并发锁和短期协调状态。
- Pino 和 OpenTelemetry 提供日志、指标和链路观测。
- `@supermind/sdk` 统一 Web 与 API 的业务契约。
- Nginx 提供同源 API、SSE 和资产代理。
